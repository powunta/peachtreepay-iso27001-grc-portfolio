# Sampled HIPAA Security Rule safeguard assessment
**Important:** Fictional gap hypotheses only; not a comprehensive HIPAA audit. "Unknown" does **not** mean the organization has violated HIPAA. "Addressable" means an organization must evaluate reasonable and appropriate implementation or document an appropriate alternative, rather than simply ignore the specification.

| ID | Safeguard and citation | Scenario status | Evidence requested |
|---|---|---|---|
| GA-01 | Risk analysis §164.308(a)(1)(ii)(A) | Gap | Current scoped risk analysis and approval |
| GA-02 | Access control §164.312(a); unique user ID §164.312(a)(2)(i) | Gap | EHR account export, HR departures, disable timestamps |
| GA-03 | Person/entity authentication §164.312(d) | Partial / Unknown | Authentication policy, portal controls, monitoring |
| GA-04 | Device/media controls §164.310(d) | Unknown | MDM encryption reports and exceptions |
| GA-05 | Transmission security §164.312(e) | Partial | Risk-based encryption determination and transmission configurations |
| GA-06 | Audit controls §164.312(b) | Partial | EHR audit logs and reviewed alert tickets |
| GA-07 | Contingency plan §164.308(a)(7) | Partial | Backup and documented restore exercise |
| GA-08 | Workforce security §164.308(a)(3) | Gap | HR termination-to-IT workflow evidence |
| GA-09 | Facility/device safeguards §164.310 | Unknown | Walkthrough and printer/media safeguards |
| GA-10 | Business associate safeguards §§164.308(b),164.314(a) | Unknown | Applicable executed BAA and due diligence |

The 24-hour EHR offboarding requirement used in the control test is **only the fictional clinic's policy**, not a universal HIPAA threshold. Multifactor authentication is a risk-treatment recommendation; do not characterize every proposed stronger MFA requirement as already enacted.
