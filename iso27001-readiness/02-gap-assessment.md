# ISO 27001 Readiness Gap Assessment

This simulated assessment compares PeachtreePay's current practices with expected security practices and identifies 12 improvement areas.

| Security area | Current state | Gap | Recommendation | Status |
|---|---|---|---|---|
| MFA | Admins only | Regular users are not consistently protected | Require MFA company-wide | Not Implemented |
| Access reviews | Informal | Permissions are not periodically reviewed | Conduct quarterly access reviews | Not Implemented |
| Offboarding | Manual email process | Accounts can be missed | Establish a formal HR/IT workflow | Partial |
| Security awareness | New-hire only | No recurring training | Add annual training and phishing exercises | Partial |
| Vulnerability management | Ad hoc | No standard remediation timelines | Establish formal scanning and remediation SLAs | Not Implemented |
| Cloud security | Engineer-managed | No formal configuration review | Establish a cloud-security baseline and reviews | Partial |
| Incident response | Basic plan exists | No consistent testing | Conduct an annual tabletop exercise | Partial |
| Backups | Automated | Restore tests are inconsistent | Perform quarterly restoration tests | Partial |
| Logging | Logs remain in separate systems | No centralized monitoring | Centralize high-value logs in a SIEM | Not Implemented |
| Vendor security | Procurement review only | Security is not formally evaluated | Establish a vendor-risk management process | Not Implemented |
| Endpoint security | Antivirus deployed | Endpoint monitoring is inconsistent | Implement EDR and standard configurations | Partial |
| Encryption | Mostly implemented | Standards are not formally documented | Document encryption requirements | Partial |

## Status Summary

- **Not Implemented:** 5 areas
- **Partial:** 7 areas
- **Implemented:** 0 areas within this gap-review sample

These statuses describe the fictional organization's assessed current state. They do not mean the portfolio deliverables are unfinished.
