# Statement of Applicability Sample

This selected-control sample records whether each ISO/IEC 27001:2022 Annex A control is applicable, its simulated implementation status, the business justification, and expected evidence.

> **Scope note:** This is a portfolio sample covering 14 relevant controls. It is not a complete organizational Statement of Applicability.

| Control | Control name | Applicable? | Status | Justification | Example evidence |
|---|---|---|---|---|---|
| A.5.15 | Access control | Yes | Partial | Employees require controlled access to sensitive systems | Access control policy; role permissions |
| A.5.16 | Identity management | Yes | Partial | User identities need lifecycle management | Provisioning/deprovisioning tickets |
| A.5.18 | Access rights | Yes | Partial | Permissions need least-privilege reviews | Quarterly access review records |
| A.5.19 | Information security in supplier relationships | Yes | Partial | PeachtreePay relies on cloud and SaaS vendors | Vendor reviews and contracts |
| A.5.23 | Information security for use of cloud services | Yes | Partial | AWS supports critical company services | Cloud baseline and configuration reviews |
| A.5.24 | Information security incident management planning and preparation | Yes | Partial | Security incidents require structured response | Incident response plan |
| A.6.3 | Information security awareness, education and training | Yes | Partial | Employees can introduce security risk | Training completion reports |
| A.6.5 | Responsibilities after termination or change of employment | Yes | Partial | Access must be removed when employment ends | Termination tickets |
| A.8.1 | User endpoint devices | Yes | Partial | Employees use laptops to access company systems | Device inventory and endpoint standards |
| A.8.7 | Protection against malware | Yes | Implemented | Endpoints require malware protection | EDR/antimalware dashboard |
| A.8.8 | Management of technical vulnerabilities | Yes | Partial | Systems require vulnerability management | Scan and remediation reports |
| A.8.13 | Information backup | Yes | Partial | Business data must be recoverable | Backup logs and restore tests |

## Status summary

- **Implemented:** 1 selected control
- **Partial:** 13 selected controls
- **Not applicable:** 0 selected controls

Applicability and implementation are different decisions: a control can be relevant to the ISMS while still requiring remediation. The evidence column identifies what an assessor could inspect to validate design and operation.
