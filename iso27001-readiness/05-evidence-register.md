# Evidence Register

This register translates control expectations into practical artifacts that an assessor could inspect. In this simulated readiness project, the entries describe **expected evidence** rather than claiming that production evidence exists.

| Control area | Example evidence | What it demonstrates |
|---|---|---|
| MFA | Microsoft 365/AWS MFA configuration report | MFA is enabled for required accounts |
| User provisioning | Approved access request tickets | Access was approved before being granted |
| Access reviews | Quarterly access review records | Permissions are periodically reviewed |
| Offboarding | Termination ticket and disabled-account record | Former employee access was removed |
| Privileged access | Administrator account inventory | Elevated access is restricted and tracked |
| Security awareness | Training completion report | Required training was completed |
| Phishing awareness | Phishing simulation results | Employees are periodically tested |
| Endpoint security | EDR dashboard/report | Endpoints are monitored and protected |
| Encryption | Device encryption compliance report | Company devices use encryption |
| Vulnerability management | Vulnerability scan report | Weaknesses are being identified |
| Patch management | Patch compliance report | Systems are receiving security updates |
| AWS security | Cloud configuration review | Cloud controls were reviewed |
| Logging | System log samples | Relevant security events are recorded |
| Monitoring | SIEM alerts and investigation tickets | Suspicious activity is reviewed |
| Backups | Backup job logs | Critical data is backed up |
| Restore testing | Restoration test record | Backups can actually be recovered |
| Vendor security | Completed vendor questionnaire | Supplier security was evaluated |
| Incident response | Tabletop exercise report | Response procedures were tested |
| Risk management | Risk register and treatment plan | Risks are identified, scored, and tracked |

## Evidence-quality checklist

Useful evidence should be:

- **Relevant:** directly supports the control being tested.
- **Reliable:** produced by an authoritative system or approved process.
- **Current:** covers the assessment period.
- **Complete:** includes the expected population, owner, date, and result.
- **Traceable:** can be linked to a risk, control, finding, or remediation item.

A policy shows that a requirement exists. Operational evidence shows whether the requirement is being performed.
