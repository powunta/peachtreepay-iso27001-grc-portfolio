This exercise uses original questions inspired by common SIG Lite / CSA CAIQ-style security assurance topics, not copied official questionnaires. It demonstrates entry-level evidence mapping, response drafting, risk identification, coordination, and escalation.

## Interview explanation
“I created an 18-question simulated SaaS customer assurance exercise. I mapped each response to a fictional evidence register and assigned review owners. I documented where control descriptions were supported by scenario facts and where uncertainty or commitments needed escalation. My main takeaway was that GRC requires defensible and reviewed claims, not simply checking ‘Yes’.”
